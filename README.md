# Mini Motorway X

仿 Apple Arcade《Mini Motorway》的極簡道路規劃遊戲。純 HTML5 Canvas,沒有任何相依套件、不需要建置,**直接用瀏覽器開啟 `index.html` 就能玩**(電腦、手機、平板皆可)。

## 玩法

- **拖曳**畫出道路,把房子連到**同顏色**的目的地,車輛就會自動出發。
- 目的地旁的**實心圓點**是還沒有車出發的需求(半透明的是車已經在路上)。實心圓點累積到上限後會出現紅色倒數圈,倒數結束(= 房子連不到目的地、或路網塞到車出不了門)就**遊戲結束**。
- 分數 = 成功送達的車輛數。
- 每週(約 75 秒)結束會出現新顏色的房子與目的地,並讓你**三選一**升級:
  | 升級 | 效果 |
  | --- | --- |
  | 紅綠燈 | 放在三岔以上的路口,同方向的車可連續通過,兩個方向輪流放行 |
  | 圓環 | 路口可同時容納兩輛車,轉彎等待更少 |
  | 橋樑 | 道路跨越河流、湖泊時每段消耗 1 個 |
  | 高速公路 | 把一般道路升級成高速路段,車速約 2 倍 |
- 車輛會依路況(壅塞、路口、速度)自動選擇最快的路線,並在進入路口前重新規劃。
- 拆除道路會把橋樑 / 高速 / 號誌退回庫存。

### 操作

| 動作 | 滑鼠 / 觸控 | 鍵盤 |
| --- | --- | --- |
| 畫道路 | 拖曳 | `1` |
| 高速公路 | 選工具後拖曳(道路上) | `2` |
| 紅綠燈 / 圓環 | 選工具後點路口 | `3` / `4` |
| 拆除 | 橡皮擦拖曳,或電腦上**右鍵**拖曳 | `5` |
| 暫停 | 右上角按鈕 | `空白鍵` |

右上角可調整遊戲速度(1× / 2× / 3×)、**介面透明度**(三段)、**全螢幕**、開關音效、重新開始。最高分與透明度設定會存在瀏覽器的 `localStorage`。

### 介面

地圖是**全畫面**的,所有控制項(分數、週進度、工具列)都是**半透明浮在地圖上**,畫路時會自動再淡出一些。預設針對**手機橫拿**設計:工具列變成左側直排、HUD 變緊湊;直拿或桌面則是底部工具列。新房子不會長在控制項底下。想獲得最佳體驗,橫放手機後按右上角的全螢幕(支援的瀏覽器會同時鎖定橫向)。

## 執行

```bash
# 方法一:直接開啟
open index.html

# 方法二:本機伺服器(任選)
python3 -m http.server 8000     # 然後打開 http://localhost:8000
```

想在手機上玩:把這個 repo 推到 GitHub,到 **Settings → Pages** 選擇分支 / 根目錄即可,它就是純靜態網站。

## 專案結構

```
index.html        頁面與 HUD、工具列
manifest.webmanifest / icon.svg   加到主畫面時以橫向全螢幕開啟(PWA 設定)
css/style.css     樣式(桌面 / 手機響應式)
js/core.js        常數、隨機數、世界格網(水域、道路邊、設施)
js/sim.js         模擬:建築生成、需求、尋路、車輛、路口、紅綠燈、每週升級
js/render.js      Canvas 繪圖(水域、道路、橋、車輛彎道平滑行駛、特效)
js/ui.js          輸入處理、HUD、彈窗、音效、主迴圈
test/sim.test.js  無頭模擬測試(單元 / 回歸情境)
test/stress.js    長時間壓力測試(機器人自動鋪路,檢查例外、死鎖、鎖洩漏)
```

模擬層(`core.js` / `sim.js`)完全不碰 DOM,可以在 Node 中直接跑:

```bash
node test/sim.test.js          # 或 npm test
node test/stress.js 12 15      # 12 個種子 x 15 分鐘
```

## 實作筆記

- 路網是**格點上的邊**:節點在格子中心,兩個相鄰節點之間可有一般道路或高速道路;房子與目的地各佔一個節點且只作為端點(車不會穿過建築)。
- 每條車道(有向邊)的車依序跟車、保持間距;三岔以上的路口有「鎖」(一般 1 輛、圓環 2 輛、紅綠燈依方向輪流放行),車必須先取得鎖才會進入路口。
- 為避免路口互相堵死(gridlock),取鎖時會在出口車道**預約一個位置**(box-junction 規則):車道內車輛 + 已預約數不能超過容量,所以持鎖的車一定能開到釋放點。長時間動彈不得的持鎖車會被拖吊並重派,當作最後防線。
- 尋路用 Dijkstra,邊成本包含速度、當前車道車數與路口等待;車輛每次進入通往路口的車道時都會重新規劃。
- 需求模型:每間房子週期性產生行程並讓目的地增加一個圓點,車輛送達才會消除。房子連不到目的地時,圓點仍會累積,這就是壓力來源。
