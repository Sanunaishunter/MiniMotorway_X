# Mini Motorway X

仿 Apple Arcade《Mini Motorway》的極簡道路規劃遊戲。純 HTML5 Canvas,沒有任何相依套件、不需要建置,**直接用瀏覽器開啟 `index.html` 就能玩**(電腦、手機、平板皆可)。

## 玩法

- **拖曳**畫出道路,把房子連到**同顏色**的目的地,車輛就會自動出發。
- 目的地旁的**實心圓點**是還沒有車出發的需求(半透明的是車已經在路上)。實心圓點累積到上限後會出現紅色倒數圈,倒數結束(= 房子連不到目的地、或路網塞到車出不了門)就是**交通癱瘓**。每個需求都是指定給某一個目的地的:同色有好幾個目的地時,沒接到路的那個**不會被其他同色目的地代打**,它的圓點會一直累積然後倒數爆掉,所以每個目的地都要接上路(見下方「市長的命令」)。
- 分數 = 成功送達的車輛數。
- 每週(約 75 秒)結束會出現新顏色的房子與目的地,並讓你**三選一**升級(從下表 6 種裡隨機給 3 種):
  | 升級 | 效果 |
  | --- | --- |
  | 紅綠燈 | 放在三岔以上的路口,同方向的車可連續通過,兩個方向輪流放行 |
  | 圓環 | 路口可同時容納兩輛車,轉彎等待更少(一次給 **4 個**) |
  | **高架** | 放在**十字路口**,兩條路立體交叉:直行不必停、不互相干擾,但**不能轉彎** |
  | **隧道** | 從入口**拖曳**到同一直線上 **2–6 格**外的出口,車子從地下穿過(可穿過水面、其他道路),速度約 1.5 倍 |
  | **超大圓環** | **5×5 格**的**單向四線道圓環**:外圈是 16 個路口、**四條車道全部同一個方向**(逆時針)繞行,中央 3×3 是綠地(有小水池),不能鋪路。選工具後點一下,以滑鼠為中心放下 5×5 的範圍(靠近地圖邊緣時會自動往內挪),**範圍內原本的路會被清掉並退回庫存**;**範圍內所有東西會自動移開**:房子和目的地搬到範圍外最近的空地(路不跟著搬,要重新接;正在開往它的車會被召回),紅綠燈 / 圓環 / 高架 / 傳送門 / 隧道 / 別的圓環都退回庫存(預覽框變琥珀色就是有東西會被移開)。要拆就用橡皮擦點中央綠地,整個圓環會退回庫存。外面的路接在圓環的外圈路口上就能進出。每週升級選單的選項之一,一次給 1 個 |
  | 高速公路 | 把一般道路升級成高速路段,車速約 2 倍 |
  | **四線道** | 把道路拓寬成**每個方向兩條車道**(一次給 **20** 段),通行量約 **1.7 倍**;不能用在連到房子的路、高速公路上 |

  這些工具取得之前不會出現在工具列上,第一次拿到才會顯示。
- 車輛會依路況(壅塞、路口、速度)自動選擇最快的路線,並在進入路口前重新規劃。
- **河流和湖面都結了冰(冰河)**,道路可以直接鋪過去,**不需要橋樑**,高速公路和四線道也可以鋪在冰上;房子與目的地仍然只會出現在陸地上。
- 拆除道路會把高速 / 四線道 / 號誌退回庫存。

### 交通癱瘓與「市長的命令」

倒數圈填滿時畫面會顯示「**交通癱瘓了!**」,但不會直接 GG,你可以選:

1. **市長的命令**:**遊戲時間暫停**(車子、倒數、週數都停住),這時可以自由改路線——畫路、拆路、放紅綠燈 / 圓環 / 高架 / 隧道都行(庫存照常計算)。畫面下方會有一顆「改好了,開始無敵時間」的按鈕,改完按下去。
2. 之後有 **5 分鐘(遊戲時間,300 秒,可在 `CFG.MAYOR_SECONDS` 調整;用 2× / 3× 速度時會更快過去)的無敵時間**:倒數圈會頂在滿格但不會再結束遊戲,這段時間內週數照常推進、可以繼續升級與鋪路,畫面下方顯示剩餘時間。
3. 無敵時間結束時,如果還有目的地是塞住的(倒數圈仍是滿的),就會顯示「**塞爆乃汽車常事,請市長重新再來**」,真正結束;如果已經疏通了,就繼續玩——但市長的命令**一局只有一次**,之後再癱瘓就是真的結束(同樣出現「重來 / 召喚 Kayray 的祝福」兩個選項)。

選「放棄,再玩一次」就是直接重新開始。

#### Kayray 的祝福

用過市長的命令之後,只要再次癱瘓(不論是無敵時間結束時還塞著,還是之後又癱瘓),就會出現「塞爆乃汽車常事,請市長重新再來」,現在有兩個選項:

- **重來**:直接重新開始(原本的行為)。
- **召喚 Kayray 的祝福**:遊戲繼續,而且進入**無限時間的無敵**——倒數圈仍會頂在滿格,但再也不會結束遊戲,週數、升級、鋪路照常進行,**直到你自己按重新開始為止**。畫面下方會顯示金色的「Kayray 的祝福 · 無限無敵」。召喚時還會送你一顆**超級原子彈**(見下一節)。(只有在用過市長的命令之後才能召喚,第一次癱瘓時仍是市長的命令。)

### 傳送門(Teleport)

**每送達 100 輛車**(分數到 100、200、300……)就會得到**一對傳送門**,工具列會出現「傳送門」(第一次拿到才顯示,鍵盤 `9`)。傳送門有兩種長相,**功能完全相同**,每次交替給:

- **藍色傳送門**:暗黑破壞神風格,石環裡一個旋轉的藍色漩渦(第 100、300、500……輛)。
- **任意門**:哆啦A夢的どこでもドア,粉紅色的門(第 200、400、600……輛)。

用法:選「傳送門」→ 點一條路的**盡頭**(只接一條路的路端)放第一扇門,再點**另一條路的盡頭**放第二扇(距離、方向不限,可以跨河、跨整張地圖)。兩扇門是**雙向**的:車子開進任何一扇,就會**瞬間傳送**到另一扇,接著從那條路繼續開。路線規劃會把它當成一條幾乎不花時間的捷徑,所以車子會自己決定要不要走。兩扇門之間有來回流動的虛線表示是一對。

限制:傳送門只能放在馬路盡頭(中間的路段、空地、房子、水面、隧道口都不行);放了之後那個路端**不能再接路**;拆掉通往傳送門的那條路,或用橡皮擦點傳送門,這一對就會整組回到庫存(保留原本的長相)。放傳送門在市長的命令暫停期間也可以。

### 超級原子彈

**召喚 Kayray 的祝福**時還會一次送你 **3 個超大圓環**和**天神之手**(見下一節),以及一顆**超級原子彈**(工具列「原子彈」,黃色按鈕)。點下去、確認後,**整張地圖的道路一次全部抹除**:一般道路、高速、四線道、紅綠燈、圓環、高架、隧道、傳送門都會**退回庫存**(可以重新鋪),路上的車也會消失、行程退回房子重新出發;房子與目的地不受影響。**一次一顆**:用掉之後,祝福會在**下一週開始時**再補一顆(庫存不會超過 1)。放完炸彈有白光、衝擊波和蕈狀雲的特效。原子彈不在每週的升級選單裡,只有祝福才拿得到。

**天神之手**(工具列金色按鈕,只有 Kayray 的祝福才拿得到,**不會用完**):點一棟**房子或目的地**把它拿起來(會出現金色虛線圈),再點一塊**空地**放下,建築就搬過去了。目標必須是空地(不能是水面、道路、設施、圓環),而且離別的建築至少隔一格。**路不會跟著搬**(原本接在那裡的路會留在原地,要重新接路);正在開往被搬走的目的地的車會被召回,行程退回房子重新出發。點自己或換工具可以取消。

### 天空中的飛機

天上會不時有**飛機**從螢幕一邊飛到另一邊(同時最多 2 架),後面拖著白色飛機雲(隱形機沒有)、地面上有淡淡的影子,翼尖有紅綠閃爍的航行燈。機型隨機,共 7 種:

- **波音 747**、**空中巴士 A380**、**波音 787**:白色客機。**機翼左右兩邊各有一條 stripe,靠近翼端**(顏色隨機),**機鼻的雷達罩是黑色的**;747 / A380 有四具發動機(A380 翼展更寬),787 兩具發動機、翼端上翹。
- **零式戰鬥機**:淡灰綠色、橢圓形直翼、兩翼的日の丸、深色發動機罩和旋轉的螺旋槳。
- **SR-71 黑鳥**:全黑的細長機身、三角翼、兩具大型發動機艙、橘色噴口。
- **B-2 幽靈**:深灰色的飛翼,後緣是雙 W 鋸齒形。
- **F-14 雄貓**:**後掠翼完全縮起**的位置,雙發動機艙、雙垂直尾翼、黑色雷達罩。

純裝飾(`js/planes.js`),跟遊戲模擬完全無關。**目前飛機群和雲朵預設都不顯示**(飛機是 `js/render.js` 的 `showPlanes`,雲朵是 `js/scenery.js` 的 `showClouds`,改成 `true` 就會再出現)。

### 交通警察

路上會隨機冒出**日本風格的巡邏車(パトカー,白底黑色車頭車尾)**,車頂的警示燈**紅、藍交替閃爍**,在你鋪的路上隨機巡邏(遇到死路會迴轉),過一陣子就消失。路越多出現越多輛(最多 3 輛)。它們**純粹是裝飾**,沒有任何功能:不佔車道、不影響其他車輛、不影響分數與路況(它們在 `js/police.js`,完全獨立於模擬之外,測試中也驗證有沒有警車模擬結果完全一樣)。

### 二線道與四線道

一般的路是**二線道**(每個方向一條車道)。**四線道**每個方向有**內、外兩條車道**,車子會自己挑比較空的那條,轉彎的車偏向外側。通行量大約是二線道的 **1.7 倍**(不是剛好兩倍:四線道的車距略大、接到路口時會有最短進入間隔,我用測試實際量過:空曠路段約 ×1.72、有路口的路段約 ×1.70)。四線道接到二線道的地方會變成**瓶頸**。路口只要接到四線道,就會變成可以同時通過兩台車的大路口。

### 畫面風格

現在有**三張地圖,每開一局隨機換一張**(不會連續兩局同一張):**雪國**、**森林**、**平原(浮世繪風格)**。右上角的地圖按鈕(鍵盤 `M`)依序切換「隨機 → 雪國 → 森林 → 平原」,選了其中一張就固定用那張,設定記在瀏覽器裡。

**平原(浮世繪)**:淡鼠尾草綠的平原(有紙紋般的細點、風吹出的草紋、綠色的暈染、小野花),水面是**普魯士藍的海**,畫著傳統的**青海波**(同心圓魚鱗紋)並緩緩漂動,海面上有北齋風格、帶爪狀浪花的白色浪頭;**浪會一波波打上岸邊再退回去**(白色的泡沫爪浪往岸上推進、退去,留下一圈變深的濕泥岸);平原上立著朱紅色的**鳥居**,遠處的陸地上有一座**富士山**(藍色山身、山腳暈染成粉紅、白色雪冠和鋸齒雪線,山腰飄著霞);樹是帶墨線的**黑松**、灌木和被海水磨圓的岩石,天上是粉米色的**霞**(一條條扁平的雲帶),還有展翅飛過的**千鳥**。海面和冰河一樣是淺灘,可以直接鋪路。

**雪國**是**北海道風格的全白雪國**:整張地圖都是白雪(淡藍色的雪窩與積雪的起伏、風吹出的雪紋、閃爍的雪光),樹是**積雪的針葉樹**、頂著雪的圓樹、光禿禿的**白樺**和雪堆,天上一直在**下雪**,冰河橫過雪原。右上角的**雪花 / 樹按鈕**(鍵盤 `M`)可以切換成**綠色森林**(含幾塊雪原,下面描述的就是這個版本),設定會記在瀏覽器裡。

森林版:整張地圖是一片**森林**:深淺不同的樹(圓葉樹、針葉樹、一叢叢粉紅色的**櫻花林**)、草地上的小花與草叢,樹**放大地圖之後**才會隨風輕輕搖擺(完整地圖時是靜止的,從約 1.1× 開始漸漸搖、1.5× 起全幅搖擺)。**水面是冰河**(淡藍色的冰、白色的霜斑與裂紋、閃爍的冰光,不會流動,結冰的河面上可以直接鋪路),天上有慢慢飄過的**卡通風格的雲**(圓滾滾的雲朵、平平的底、淡藍色的雲底和描邊,半透明,地面上有淡淡的雲影)和飄落的花瓣。房子與目的地底下有一小塊空地,讓顏色在草地上也看得清楚。地圖上還有**雪地**:每局隨機有一兩塊(約佔三成)雪原,地面是白雪、有藍色的雪堆陰影和閃爍的雪光,樹變成**積雪的針葉樹**、頂著雪的圓樹和雪堆,雪地上空會下雪(櫻花瓣則不會飄進雪地)。這些都只是裝飾,不影響玩法。

### 晝夜(永晝 / 永夜 / 晝夜交替)

右上角的**太陽 / 月亮 / 半月按鈕**(鍵盤 `N`)可以在三種模式間切換,設定會記在瀏覽器裡:**晝夜交替**(預設,約每 2 週 = 150 秒一輪:白天、黃昏、夜晚、黎明)、**永晝**、**永夜**。天黑時整張地圖會變成藍紫色的夜色,同時亮起:**車頭燈**(前方的光錐)與**紅色尾燈**、路邊的**街燈**、**紅綠燈**的燈號光暈、**隧道口**的橘光、**房子的窗戶**(帶著該房子顏色的光暈,顏色仍然一眼就看得出來)、**目的地**的彩色光,以及警車閃得更亮的紅藍燈。純粹是畫面效果,不影響玩法。

### 日本風格的道路

道路畫成日本的樣子:深灰色柏油、白色外側線、兩旁的淺色人行道、白色虛線的中央線;路口每個方向都有**斑馬線**和**停止線**,一般路口還立著紅色倒三角的**「止まれ」**標誌;路邊零星有**電線桿**;**高速公路**是更深的柏油加綠色路肩,出入口有綠色指示牌;隧道口有一排橘色的燈。車子仍然**靠右行駛**,而且有各種日本常見的車型:**輕自動車**(短而方)、**廂型車**、**輕型貨車**(前面駕駛艙、後面載貨台)、車頂有行燈的**計程車**,一般轎車。車子的**顏色**仍然代表目的地的顏色,車型只是裝飾。

#### 跑車:一台抵 5 台

約 **7%** 的車是**跑車**,車頂上方有金色的「5」徽章:**Mazda 787B**(1991 年勒芒冠軍的 Group C 原型車:低趴寬身、外露的寬輪胎、泡泡座艙、車尾大尾翼、白色 + 綠色的 Renown 塗裝細節)和 **Porsche 911**(圓潤的雙門跑車、圓形大燈、長長斜下的車頂、鴨尾)。車身顏色一樣是目的地的顏色。**一台跑車抵 5 台普通車**:

- 送達時**分數 +5**(也會算進每 100 輛送傳送門的進度),畫面跳出金色的「+5」和光環;
- 同時**抵銷最多 4 個還在等車的需求**(同一個目的地、同色房子排隊中的行程,先抵銷自己那間房子的),目的地的實心圓點一次少掉最多 5 個。如果當時只有 2 個在等,就只抵銷那 2 個。

跑車是按車輛編號決定的(不用亂數,不影響其他隨機事件),速度和一般車一樣,只是更值錢。

### 介面

畫面由上到下是三條:**上方資訊列**(分數、週進度、控制按鈕)、**中間的地圖**、**下方工具列**(工具多的時候會自動排成**上下兩排**)。地圖夾在兩列中間、完全不會被蓋住,所以新長出來的房子和目的地一定看得到。預設針對**手機橫拿**設計:兩條列都做得很薄,讓地圖保留最大的高度;直拿和桌面則是較寬鬆的版面。想要更大的畫面,橫放手機後按右上角的全螢幕(支援的瀏覽器會同時鎖定橫向)。

地圖的格數依「兩條列中間」的大小自動決定,約 400–750 格(例如橫放的手機約 38×13、桌機約 37×20)。想看細節時用上面說的兩指捏合放大、兩指拖曳移動。

## 實作筆記

- 路網是**格點上的邊**:節點在格子中心,兩個相鄰節點之間可有一般道路或高速道路(邊可以是**單向**;引擎裡有一個用 8 條單向邊組成的 3×3「大圓環」,目前沒有放進遊戲裡,但仍有測試);房子與目的地各佔一個節點且只作為端點(車不會穿過建築)。
- **隧道**是一條跳過中間格子的「長邊」,所以天生和地面道路互不干擾;車道長度大於 1 格,跟車距離、停止線、取鎖的容量都會依車道長度換算。**高架**是不能轉彎、不需要鎖的十字節點。尋路因此改成對「(節點, 進入方向)」做 Dijkstra,才能表達不可迴轉與高架不能轉彎。
- 每條車道(有向邊)的車依序跟車、保持間距;**四線道**的車道有兩個「槽位」,只跟同槽位的車比車距(車距乘上 `WIDE_GAP` = 1.18,所以兩槽合計約 1.7 倍),路口鎖的容量與出口預約也都逐槽位計算;三岔以上的路口有「鎖」(一般 1 輛、圓環 2 輛、紅綠燈依方向輪流放行),車必須先取得鎖才會進入路口。
- 為避免路口互相堵死(gridlock),取鎖時會在出口車道**預約一個位置**(box-junction 規則):車道內車輛 + 已預約數不能超過容量,所以持鎖的車一定能開到釋放點。長時間動彈不得的持鎖車會被拖吊並重派,當作最後防線。
- 尋路用 Dijkstra,邊成本包含速度、當前車道車數與路口等待;車輛每次進入通往路口的車道時都會重新規劃。
- **狀態機**:`running` →(倒數滿)`collapse` →(市長的命令)`mayor`(時間凍結、可編輯)→(改好了)`running` + 無敵視窗 →(視窗結束仍塞住,或之後再次癱瘓;`mayorUses > 0` 時 `collapse()` 直接走 `gameOver(dest, true)`)`over` →(Kayray 的祝福)`running` + 永久無敵;放棄則由 `collapse` 直接到結束。編輯 API 的檢查是 `canEdit()`(`running` 或 `mayor`)。無敵期間倒數圈夾在 1,視窗結束的那一刻才判定。
- **傳送門**是路網圖裡的一條**雙向跳躍邊**(`World.tp`:兩個方向各存一筆,`World.portal` 記錄長相與配對):`route()` 在門節點多一條成本 `CFG.PORTAL_COST` 的邊,抵達另一扇門時方向設為「無方向」(`-1`),所以那條路可以往任何方向開。車的路徑是 `[… P, 門A, 門B, Q …]`,`stepCar` 偵測到「這條車道的終點是門、下一個節點是它的配對」就在車道末端把車瞬移到 Q 車道起點(沒空位就在門前排隊)。傳送門節點必須恰好接一條路,因此不是路口、不需要鎖,也不會打亂路口鎖 / 預約的帳目;`validateCars` 透過 `edgeBetween`(門→配對門回傳 4)認得這條邊,拆掉時車子會被改道或召回。每 `CFG.PORTAL_EVERY`(100)輛送達就由 `grantPortals()` 發一對,樣式依序輪流。
- **超級原子彈**:`nuke()` 依序拆掉傳送門、隧道、大圓環、設施,再清掉所有路段並把高速 / 四線道退回庫存,最後 `validateCars()` 讓所有車退回(行程回到房子)。`inv.nuke` 只由 `kayrayBlessing()`(設為 1)與 `advanceWeek()`(祝福中且庫存為 0 時補 1)給。
- **Kayray 的祝福**:`kayrayBlessing()` 只在最終失敗(`state === 'over'` 且 `over.final`)時可用,把狀態切回 `running` 並設 `blessed = true`;`step()` 裡 `shielded = blessed || time < invincibleUntil`,所以倒數圈永遠夾在 1、不會再 `collapse`,直到重新開局(新的 `Game`)才解除。
- 需求模型:每間房子週期性產生行程並讓目的地增加一個圓點,車輛送達才會消除。房子連不到目的地時,圓點仍會累積,這就是壓力來源。
